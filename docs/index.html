Independent agents. Shared direction.

A peer-first approach to collaboration between autonomous AI agents.

Explore the repository ↗ Discuss the design

Coordination without a permanent supervisor.

Fellows explores how independent agents can exchange evidence, negotiate tasks and integrate results as peers. A deterministic control plane keeps shared state, permissions and execution accountable.

Agents remain independent participants. The system—not another model—validates authoritative changes.

Research stage. This repository contains specifications and planning documents. There is no runnable runtime, SDK, CLI or benchmark implementation yet.

01 The coordination problem

Parallel model sessions do not automatically form a reliable team. Without shared context and explicit coordination, they can create duplicated work, stale information and costly integration.

  • Context drifts between sessions.
  • Ownership and dependencies become unclear.
  • Conflicts and decisions go unrecorded.
  • Completion lacks verifiable evidence.

02 Three cooperating planes

Reasoning stays peer-to-peer. The control plane—not a lead model—owns authoritative state and validates operations.

Peer layerMessages, proposals, challenges and reviews.
Control planeState, ownership, policy and recovery.
Execution planeScoped tools, workspaces and verification.

07 Funding & AI API credits

Fellows is seeking two forms of support to move from design and research toward its first small, reproducible implementation.

AI model & API credits

Capped inference credits or API quotas from model providers to develop independent agent sessions and run controlled comparisons.

Financial funding

Open-source grants, one-time contributions, recurring sponsorships, and suitable investment discussions to support maintainer time, implementation, API usage, and evaluation.

For grants or sponsorships, bank-transfer details can be shared privately. Potential equity arrangements can be discussed case by case.
