# Funding and AI API credits

Fellows is an early-stage, open-source research project. The current request is intentionally limited to two categories.

## 1. AI model and API credits

We are looking for capped API credits, inference quotas, or research allocations from model providers.

These resources would be used to:

- develop and test independent agent sessions;
- compare the peer-first approach with single-agent and orchestrated baselines;
- measure output quality, token usage, latency, and provider-reported cost.

Credits would be used within the provider's terms. We do not imply an existing partnership or entitlement to free access.

## 2. Financial funding

We are open to:

- open-source project grants;
- one-time project contributions;
- recurring sponsorships;
- suitable investment discussions, including potential equity arrangements.

Financial support would fund maintainer time, the first runtime implementation, model API usage, controlled evaluation, and release preparation. Any investment or equity arrangement would be discussed separately and documented on its own terms.

Bank-transfer details are available on request. Contact **[okay.fellows@gmail.com](mailto:okay.fellows@gmail.com)**.

## What we are not requesting

Fellows is not requesting GPUs, compute, cloud hosting, storage, infrastructure, developer-tool subscriptions, mentorship, or general consulting.

## Current project stage

The repository contains architecture and research specifications. There is no runnable runtime, SDK, CLI, or benchmark implementation yet. Funding discussions should be based on that current status, not on assumed product capabilities or traction.
